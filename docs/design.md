# 仮設計

学祭のリアル人生ゲームで使う電子カードと財布です。QRから開き、カード1枚で出来事・金額・移動数を決めます。

## 位置と年代

現在位置を0から開始し、カードの移動数を加減算します。位置は0～50マスに制限します。

| 到達位置 | 年代・状態 |
| --- | --- |
| 0マス | 学生 |
| 10マス | 社会人 |
| 30マス | 老後 |
| 50マス | ゴール・自動終了 |

境界を飛び越えても切り替えます。最高到達位置を保存して年代フラグを管理し、戻るカードでも年代は戻りません。手動の年代切り替えは廃止しました。アプリはカードの指示から位置を計算し、実際に移動したかは判定しません。マス固有のイベントも設けません。

## 設定

`cards.js`の`gameConfig`で初期所持金・ゴール・年代を編集します。`eras`は`id`・表示名`label`・開始位置`startAt`を持ちます。開始位置は0から昇順で設定します。ゴールは`goal: 50`です。

各カードは一意の`id`、対象年代`era`、出来事`title`、円単位の整数`money`、移動数の整数`move`、任意のアイコン`icon`を持ちます。各年代に1枚以上のカードが必要です。仮実装は各6枚、計18枚で、初期所持金は100,000円、マイナス残高は許可します。設定変更時は`version`も更新します。

## 進行と山札

1. 開始時に年代別の山札をFisher–Yates方式でシャッフルします。
2. 現在の年代の山札から1枚引き、金額を一度だけ反映します。
3. 移動数から現在位置と最高到達位置を更新します。
4. 最高到達位置から年代を更新し、次の抽選からその年代の山札を使います。
5. 50マス到達なら自動終了し、最終所持金を表示します。
6. 状態を保存します。

山札が空ならその年代のカードだけを再シャッフルします。一巡するまでは同じIDを引きません。一巡の境目は同じカードが続く場合があります。年代変更自体では所持金を変更しません。境界を越えたカードは元の年代を表示して内容を維持します。

## 画面

開始画面では新規開始・再開を選びます。プレイ画面は所持金・現在の年代・位置と進捗・カード・抽選・やり直し・途中終了を表示します。結果画面では最終所持金を表示します。

やり直しと途中終了は確認後に実行します。50マス到達は確認不要です。抽選直後は短時間ボタンを無効にし、終了後は抽選できません。カードサイズは内容で変えず、小さい画面では余白と全体の縮小で画面内に収めます。

## 保存

保存先は`localStorage`、キーは`lifeGame.state`、保存形式は`schemaVersion: 3`です。所持金、現在位置、最高到達位置、年代、年代別の山札と抽選枚数、直近のカードID、総抽選枚数、状態、設定バージョンを保存します。

再開時は保存状態を復元するだけで金額や移動を再適用しません。位置・年代の整合性、山札のID・重複・枚数などを検証します。旧形式や破損記録は再開できず、新しく始める案内を表示します。新規開始を確定するまで記録は上書きしません。保存不可でもページを開いている間は遊べます。

## 公開と確認

HTML・CSS・JavaScriptで実装し、GitHub Pagesへの公開を予定しています。相対パスでアセットを参照し、公開URLをQRにします。名前・ランキング・ログイン・サーバーへの参加者データ送信・端末間引き継ぎ・オフライン起動は対象外です。

`node --test tests/game.test.cjs`で山札、収支、保存・再開、連打防止、確認キャンセル、終了、保存不可時の継続を確認します。位置管理では10・30マスの境界、飛び越え、後退時の年代維持、0マスの下限、50マスの自動終了を確認します。画面テストは簡易DOMを使用し、実機の見た目と操作は別途確認します。

カードの内容と移動数は友人の試遊後に調整します。

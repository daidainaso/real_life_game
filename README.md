# リアル人生ゲーム

学祭のリアル人生ゲームで使う、スマートフォン向けWebアプリです。参加者がQRコードからアクセスし、カードの指示に従って実際の盤面を移動します。アプリがカード抽選、所持金、現在位置、年代を管理します。

HTML・CSS・JavaScriptのみで動作し、ビルドや追加パッケージのインストールは不要です。

## 主な機能

- 年代別のカード抽選と山札の自動シャッフル
- 所持金と現在位置の自動計算
- 学生・社会人・老後への自動切り替え
- ゴールでの最終所持金表示
- ブラウザ内への保存と途中再開
- 確認付きのやり直し・途中終了
- スマートフォンの画面サイズに合わせた表示

## 遊び方

1. Webアプリを開き、「ゲーム開始」を押します。
2. 「カードを引く」を押すと、出来事・所持金の増減・移動数が表示されます。
3. 指示された数だけ実際の盤面を移動します。
4. 移動後に次のカードを引き、50マスのゴールを目指します。

保存されたゲームがある場合は「続きから再開」を選べます。

## ルール

| 項目 | 設定 |
| --- | --- |
| 初期所持金 | 100,000円 |
| 学生 | 0マスから開始 |
| 社会人 | 10マス到達で切り替え |
| 老後 | 30マス到達で切り替え |
| ゴール | 50マス到達で自動終了 |
| カード | 各年代6枚、計18枚 |

年代は最高到達位置に応じて切り替わります。一度到達した年代は、戻るカードを引いても維持します。現在位置は0～50マスの範囲に収めます。所持金のマイナスは許可します。

山札は年代ごとに独立しています。一巡するまで同じカードを引かず、使い切るとその年代のカードを再シャッフルします。年代の切り替え後は、次の抽選から新しい年代の山札を使用します。

カードの内容と数値はサンプルです。開催するゲームに合わせて変更できます。

## ローカルで起動する

このフォルダで次のコマンドを実行します。Python 3が必要です。

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで <http://localhost:8000/> を開きます。サーバーの停止は`Ctrl+C`です。

`index.html`を直接開いて試すこともできますが、保存を確認する場合はHTTPサーバー経由でアクセスしてください。

## カード・ルールの変更

[cards.js](cards.js)に設定とカード一覧をまとめています。

```javascript
const gameConfig = {
  version: 3,
  initialMoney: 100000,
  goal: 50,
  eras: [
    { id: "student", label: "学生", startAt: 0 },
    { id: "adult", label: "社会人", startAt: 10 },
    { id: "senior", label: "老後", startAt: 30 },
  ],
};
```

カードは以下の形式です。

```javascript
{
  id: "work",
  era: "student",
  title: "アルバイトを頑張った",
  money: 10000,
  move: 3,
  icon: "☕"
}
```

| 項目 | 内容 |
| --- | --- |
| `id` | カードごとに一意のID |
| `era` | 対象年代のID |
| `title` | 出来事の文面 |
| `money` | 所持金の増減額。負の数は支出 |
| `move` | 移動数。負の数は戻る、0は移動なし |
| `icon` | 任意のアイコン |

各年代に1枚以上のカードを用意してください。年代の開始位置は0から昇順で設定します。カードやルールを変更した場合は`version`を更新し、既存の保存データとの不整合を防ぎます。

## GitHub Pagesでの公開

静的ファイルをGitHub Pagesで配信できる構成です。公開元には`index.html`、`style.css`、`cards.js`、`script.js`を含めます。CSS・JavaScriptは相対パスで参照しています。

公開後のURLをQRコードにして配布します。印刷後はURLを維持し、同じURLの内容を更新してください。

## テスト

Node.jsがある環境で、追加パッケージなしで実行できます。

```sh
node --test tests/game.test.cjs
```

山札、金額計算、位置と年代の切り替え、ゴール、保存データの検証、再開、連打防止、確認のキャンセルなどを検証します。画面処理は簡易DOM環境で確認しているため、実ブラウザ・スマートフォンでの表示と操作は別途確認してください。

## データ保存

ゲームの状態は参加者のブラウザの`localStorage`に保存します。再開には同じ端末・ブラウザ・公開元を使用します。ブラウザのデータを削除すると記録は失われます。

保存できない環境でも、そのページを開いている間は遊べます。端末間の引き継ぎと複数タブでの同時プレイには対応していません。ログイン・名前入力・ランキング・参加者データのサーバー送信は行いません。
